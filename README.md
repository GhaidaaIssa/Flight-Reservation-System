# ✈️ Flight & Seat Reservation System (C++)

A robust and object-oriented C++ application designed for managing flight seats and ticket reservations efficiently.

## 🌟 Key Features
* **Object-Oriented Design (OOP):** Built using inheritance and polymorphism for standard and premium seat logic (`Seat`, `Business`, `Economy`).
* **Error & Exception Handling:** Custom exception framework (`SystemException`) ensuring software stability against invalid inputs or booking collisions.
* **File Persistence:** Automatically saves and loads booking records and reports to/from persistent storage (`flight_data.txt`, `flight_report.txt`).
* **Interactive CLI:** Clean, user-friendly command-line interface with input validation.

## 🛠️ Built With
* **C++** (C++11 or higher)
* Standard Template Library (STL)
* File I/O Streams (`fstream`)
